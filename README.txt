BLOCKX - APK PACKAGE
====================

PATH A (pinakadali, walay coding): PWABuilder
1. Ablihi ang https://app.netlify.com/drop  ug i-drag ang folder "www" niini. Makakuha ka ug https link.
2. Ablihi ang https://www.pwabuilder.com , i-paste ang link, i-click Start.
3. Package for stores > Android > Generate. I-download ang zip ug kuhaa ang .apk sa sulod.
   (Para sa Play Store ang .aab; para i-install sa phone, ang .apk.)

PATH B (GitHub, awtomatiko nga build sa APK)
1. Mag-sign up sa https://github.com ug himoa ang bag-ong repository (libre).
2. I-upload ang TANANG sulod niini nga folder (lakip ang ".github" nga folder).
3. Adto sa tab nga "Actions" > "Build BlockX APK" > Run workflow (o maghulat, mo-run ra kini kada upload).
4. Pagkahuman (mga 5-10 minutos), i-click ang pinakabag-o nga run > Artifacts > "BlockX-apk" > i-download.
   Kuhaa ang "app-debug.apk" sa zip.

PAG-INSTALL SA ANDROID
- I-copy ang .apk sa phone, i-tap, ug i-allow ang "Install unknown apps" kung mangayo.
- Ang iPhone dili mo-install ug .apk. Para sa iPhone: ablihi ang link sa Safari > Share > Add to Home Screen.

PAG-USAB SA GAME
- Usba ang www/index.html (ang code sa game), dayon i-upload ulit.
